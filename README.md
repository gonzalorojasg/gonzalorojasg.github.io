# gonzalorojasg.github.io

Sitio personal de Gonzalo Rojas García: astrofísica, divulgación y docencia.
Publicado en https://gonzalorojasg.github.io

## Estructura

```
index.html      ← todo el contenido (textos en ES y EN)
css/style.css   ← diseño y colores (paleta al inicio del archivo)
js/main.js      ← botón de idioma y animación de la curva de luz
assets/         ← foto, CV en PDF, imágenes de divulgación
```

## Cómo editar

- Cada texto aparece dos veces: `<span class="es">…</span>` y `<span class="en">…</span>`. Si cambias uno, cambia el otro.
- Busca `TU_` en `index.html` para completar correo, ORCID, LinkedIn e Instagram.
- Para agregar una publicación, copia un bloque `<li>` dentro de `<ol class="pubs">`.
